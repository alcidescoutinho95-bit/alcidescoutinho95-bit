## 📂 O que você encontrará por aqui

Os projetos deste GitHub são voltados principalmente para **Engenharia de Dados**, explorando problemas e soluções relacionados a:

* Construção de pipelines **ETL/ELT**
* Ingestão de dados de APIs e bancos de dados
* Processamento distribuído com **Spark/PySpark**
* Arquiteturas **Medallion e Lakehouse**
* **Databricks, Delta Lake e Unity Catalog**
* Orquestração de pipelines com **Airflow**
* Containers e ambientes de desenvolvimento com **Docker**
* Integração e transformação de diferentes fontes de dados
* Data Quality e validação de dados
* Modelagem e construção de datamarts
* Controle, versionamento e governança de dados
* Automação e práticas de CI/CD
* Projetos envolvendo dados públicos e APIs

A ideia é manter os repositórios como um espaço para projetos práticos, estudos e experimentações com tecnologias utilizadas no ecossistema de dados.
